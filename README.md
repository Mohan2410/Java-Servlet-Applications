# Java Servlet Applications

A collection of Java Web Applications developed while learning and practicing
Java Servlets, JSP, JDBC, JavaBeans, DAO, MVC architecture, and Oracle Database.

This repository contains multiple applications created during my learning and
hands-on practice with Java-based web development.

---

## 📌 About the Repository

This repository contains different Java Servlet and JSP applications that
demonstrate how a Java web application works from the frontend to the database.

The applications cover concepts such as:

- Java Servlets
- JSP (JavaServer Pages)
- HTTP GET and POST requests
- Request and Response handling
- RequestDispatcher
- JavaBeans
- JDBC
- DAO (Data Access Object)
- CRUD operations
- Session and Cookie management
- MVC architecture
- Oracle Database connectivity
- Apache Tomcat
